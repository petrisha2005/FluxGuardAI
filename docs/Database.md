# Database Architecture & Documentation

This document describes the PostgreSQL database architecture implemented for **FluxGuard AI v1.1**.

## Configuration
The database connection parameters are configured via environment variables.

- **Primary Driver**: PostgreSQL (`psycopg2` or `asyncpg`)
- **Connection String Key**: `DATABASE_URL`
- **Fallback Database**: SQLite (In-Memory `sqlite:///:memory:` or local file `sqlite:///fluxguard_dev.db`) is automatically activated if the connection to the primary PostgreSQL server fails.

### Connection Properties (`.env`)
```ini
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/fluxguard
```

## Schema & Tables

### 1. `users`
Represents operational users, operators, administrators, and volunteers.
- `id` (GUID, PK)
- `name` (String, Not Null)
- `email` (String, Unique, Not Null, Indexed)
- `password_hash` (String, Not Null)
- `role` (String, Not Null) - `fan`, `volunteer`, `operator`, `organizer`, `admin`
- `preferred_language` (String, Default: `en`)
- `created_at` (DateTime)

### 2. `stadiums`
Represents physical venues monitored by FluxGuard.
- `id` (GUID, PK)
- `name` (String, Not Null)
- `city` (String, Not Null)
- `country` (String, Not Null)
- `capacity` (Integer, Not Null)
- `latitude` (Float, Not Null)
- `longitude` (Float, Not Null)

### 3. `events`
Represents specific stadium events (e.g., matches, concerts) scheduled for monitoring.
- `id` (GUID, PK)
- `stadium_id` (GUID, FK -> `stadiums.id`)
- `name` (String, Not Null)
- `date` (DateTime, Not Null)
- `attendance` (Integer, Nullable)
- `description` (String, Nullable)
- `status` (String, Default: `active`)
- `starts_at` (DateTime, Not Null)
- `ends_at` (DateTime, Not Null)

### 4. `zones`
Represents segments of a stadium (e.g., gates, concourses).
- `id` (GUID, PK)
- `event_id` (GUID, FK -> `events.id`)
- `parent_zone_id` (GUID, FK -> `zones.id`, Nullable)
- `name` (String, Not Null)
- `zone_type` (String, Not Null) - `gate`, `concourse`, `stand`, `transit`, etc.
- `capacity` (Integer, Not Null)
- `status` (String, Default: `open`)

### 5. `crowd_measurements`
Time-series crowd state telemetry ingested from camera sensors/simulators.
- `id` (GUID, PK)
- `zone_id` (GUID, FK -> `zones.id`)
- `measured_at` (DateTime, Not Null)
- `density_count` (Integer, Not Null)
- `flow_rate_per_minute` (Integer, Not Null)
- `queue_length` (Integer, Not Null)
- `source_type` (String, Not Null)
- `confidence` (Float, Not Null)
- `ingested_at` (DateTime)

### 6. `predictions`
Crowd state forecasts produced by the Predictive Intelligence Engine.
- `id` (GUID, PK)
- `zone_id` (GUID, FK -> `zones.id`)
- `horizon_minutes` (Integer, Not Null) - `10`, `20`, `40`, `60`
- `predicted_density` (Integer, Not Null)
- `predicted_queue_length` (Integer, Not Null)
- `predicted_flow_rate` (Integer, Not Null)
- `confidence_interval_low` (Float, Not Null)
- `confidence_interval_high` (Float, Not Null)
- `generated_at` (DateTime, Not Null)
- `model_version` (String, Not Null)

### 7. `risk_scores`
Real-time risk scoring output compiled by the risk assessment models.
- `id` (GUID, PK)
- `zone_id` (GUID, FK -> `zones.id`, Unique)
- `risk_score` (Integer, Not Null) - `0` to `100`
- `severity` (String, Not Null) - `low`, `medium`, `high`, `critical`
- `drivers_json` (JSON, Not Null)
- `prediction_horizon_minutes` (Integer, Not Null)
- `generated_at` (DateTime, Not Null)

### 8. `alerts`
Incidents triggered when risk scores cross severity thresholds.
- `id` (GUID, PK)
- `zone_id` (GUID, FK -> `zones.id`)
- `severity` (String, Not Null)
- `status` (String, Default: `open`) - `open`, `acknowledged`, `in_progress`, `resolved`
- `title` (String, Not Null)
- `description` (String, Not Null)
- `timestamp` (DateTime, Not Null)
- `assignee` (String, Nullable)
- `notes` (String, Nullable)

### 9. `guidance_messages`
Operational directives generated by the AI Copilot.
- `id` (GUID, PK)
- `alert_id` (GUID, FK -> `alerts.id`)
- `audience_role` (String, Not Null) - `fan`, `volunteer`, `operator`, `organizer`
- `severity` (String, Not Null)
- `headline` (String, Not Null)
- `actions_json` (JSON, Not Null)
- `expires_at` (DateTime, Not Null)
- `payload_json` (JSON, Not Null)
- `prompt_version` (String, Not Null)
- `schema_version` (String, Not Null)
- `model_provider` (String, Not Null)
- `model_name` (String, Not Null)
- `input_context_hash` (String, Not Null)
- `status` (String, Default: `PENDING_APPROVAL`)

### 10. `incidents`
Active ticket registry for physical incidents reported in stadium zones.
- `id` (GUID, PK)
- `event_id` (GUID, FK -> `events.id`)
- `zone_id` (GUID, FK -> `zones.id`, Nullable)
- `type` (String, Not Null)
- `severity` (String, Not Null)
- `status` (String, Not Null) - `REPORTED`, `DISPATCHED`, `RESOLVED`
- `location` (String, Nullable)
- `created_at` (DateTime)
- `resolved_at` (DateTime, Nullable)
- `description` (String, Nullable)
- `responder_name` (String, Nullable)

### 11. `volunteers`
Steward and first responder directory.
- `id` (GUID, PK)
- `name` (String, Not Null)
- `language` (String, Not Null)
- `skill` (String, Not Null)
- `availability` (String, Not Null)
- `assigned_zone` (String, Nullable)

### 12. `agent_decisions`
Proposed actions generated by the autonomous operations agents.
- `id` (GUID, PK)
- `agent_name` (String, Not Null)
- `recommendation` (String, Not Null)
- `confidence` (Integer, Not Null)
- `status` (String, Default: `PENDING_APPROVAL`)
- `created_at` (DateTime)
- `expected_impact` (String, Nullable)
- `reason` (String, Nullable)
- `target` (String, Nullable)

### 13. `action_executions`
Audit log of autonomous agent executions.
- `id` (GUID, PK)
- `decision_id` (GUID, FK -> `agent_decisions.id`)
- `action` (String, Not Null)
- `result` (String, Not Null)
- `execution_time` (DateTime)
- `operator` (String, Nullable)
- `impact` (String, Nullable)

### 14. `historical_records`
Closed operational archives for training retrieval and scenario playback.
- `id` (GUID, PK)
- `event_name` (String, Not Null)
- `action` (String, Not Null)
- `outcome` (String, Not Null)
- `effectiveness` (Integer, Not Null)
- `historical_success_rate` (String, Nullable)

### 15. `audit_logs`
System-wide security and operations auditing trail.
- `id` (GUID, PK)
- `user` (String, Not Null)
- `action` (String, Not Null)
- `timestamp` (DateTime)
- `metadata_json` (JSON)

### 16. `cameras`
Optical sensor configuration and status.
- `id` (GUID, PK)
- `zone_id` (GUID, FK -> `zones.id`)
- `name` (String, Not Null)
- `fps` (Integer, Default: `30`)
- `accuracy` (Float, Default: `0.95`)
- `status` (String, Default: `active`)

### 17. `zone_staffing`
Current deployment counts of stewards in stadium zones.
- `id` (GUID, PK)
- `event_id` (GUID, FK -> `events.id`)
- `zone_id` (GUID, FK -> `zones.id`)
- `count` (Integer, Default: `0`)

### 18. `interventions`
Operational changes deployed to mitigate critical crowds.
- `id` (GUID, PK)
- `event_id` (GUID, FK -> `events.id`)
- `zone_id` (GUID, FK -> `zones.id`)
- `type` (String, Not Null)
- `description` (String, Not Null)
- `trigger_tick` (Integer, Not Null)
- `pre_density` (Integer, Not Null)
- `pre_risk` (String, Not Null)
- `post_density` (Integer, Nullable)
- `post_risk` (String, Nullable)
- `timestamp` (DateTime)
