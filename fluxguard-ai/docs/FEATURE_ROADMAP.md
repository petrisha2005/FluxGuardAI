# Feature Roadmap

## MVP

- Event, venue, zone, and capacity configuration.
- Simulated crowd data generator.
- Zone-level crowd density dashboard.
- Prophet or baseline LSTM forecasting for 20, 30, and 40 minute horizons.
- Risk scoring engine.
- Alert creation and status management.
- Claude-generated guidance for fans, volunteers, and operators.
- Structured JSON guidance validation.
- WebSocket live updates.
- Supabase persistence.
- Basic authentication and role-based access.
- Accessibility-first responsive UI plan.
- Manual feedback capture.

## Version 2

- Real-time integration adapters for ticket scans, gates, transit, and weather.
- Improved model selection by zone type.
- Confidence intervals and forecast explainability.
- Multi-language fan guidance.
- Operator approval workflows.
- Incident management integration.
- Staffing recommendations.
- Signage and public announcement integrations.
- Advanced analytics for intervention effectiveness.
- Offline-tolerant volunteer mode.
- Anomaly detection for sudden crowd surges.

## Future Vision

- Multi-venue orchestration across an entire tournament city.
- Digital twin simulation of pedestrian flows.
- Computer vision crowd-density integration.
- Reinforcement learning for dynamic routing.
- Personalized accessibility-aware routes.
- Integration with emergency services command systems.
- Predictive staffing and concession demand planning.
- Automated post-event safety reports.
- Federated learning across venues without exposing sensitive raw data.
